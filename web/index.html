Uno R3 · Web Serial firmware writer

USBからプログラムを書き込む

Arduino IDEを起動せず、Arduino Uno R3へ動作確認済みの「可変抵抗 → 4系統DShot300」プログラムを書き込みます。

Arduino Uno R3 専用Windows · Chrome / Edge書き込み後に読み戻し検証

書き込むファームウェア

GitHub Actionsで、リポジトリの最新スケッチからビルドしたHEXを使用します。ソースコードの編集や自動改変はしません。

対象ATmega328P / 16MHz
信号出力D8・D9・D10・D11
ファームウェア読み込み中
コードの版：確認中　 ·　 HEXを保存

書き込み

  1. モーターのプロペラを外し、ESCのLiPoを取り外します。
  2. Uno R3をUSBケーブルでPCへ接続します。
  3. Arduino IDEのシリアルモニタ等、COMポートを使用するソフトを閉じます。
  4. 下の確認欄をチェックして「接続して書き込む」を押し、UnoのCOMポートを選択します。
書き込み操作により現在Unoに入っているプログラムは上書きされます。ESCは別途バッテリー給電のため、書き込み中は必ずLiPoを外してください。
最新ファームウェアを読み込んでいます。

配線・プログラムの動作

    

      
可変抵抗両端：5V / GND、中央端子：A0

      
ESC信号D8 / D9 / D10 / D11から単方向DShot300

      
停止つまみ最小でDShot 0を送信

      
起動条件電源投入後3秒停止→つまみ最小を0.6秒保持

    

    
パソコンに認識されない場合はデータ通信対応USBケーブルを確認してください。Unoの互換品によっては別途USBシリアルドライバが必要です。標準Uno R3のOptiboot（115200bps/STK500v1）が対象です。
